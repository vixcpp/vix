# Interactive C++ REPL

The interactive REPL is not included in the Vix 3.0 stable CLI command surface.

The historical Reply evaluator is not a persistent C++ interpreter, so `vix repl` is intentionally unavailable in this release. Running `vix` without a command displays CLI help. This page is retained as a route for older links; its examples and instructions do not describe Vix 3.0 behavior.
